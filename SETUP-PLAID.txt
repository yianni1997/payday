LIVE BANK CONNECTIONS (PLAID) - ONE-TIME SETUP, about 30 minutes, easiest on a computer
=====================================================================================
What this does: the Accounts tab connects Chase and PayPal. One tap then pulls every
charge for your current paycheck into Review. Your Plaid keys live on a tiny private
server in YOUR Google account. The app and GitHub never see them.

You need the Sync / Google sign-in from README.txt already working (same Firebase project).

PART A - PLAID (plaid.com)
1. Go to dashboard.plaid.com/signup. Choose "Personal use". This is the free Trial plan
   (real bank data, up to 10 connected logins). Confirm "Transactions" is included.
2. In the dashboard open Developers > Keys. Copy your client_id and your Production secret.
3. Developers > API > Allowed redirect URIs: add your site address EXACTLY, with the
   slash at the end, for example:   https://yianni1997.github.io/Payday/
   (Chase signs you in on its own page and sends you back here, so this is required.)

PART B - YOUR PRIVATE SERVER (console.cloud.google.com)
1. Open console.cloud.google.com and pick your Payday project (the same one as Firebase).
2. Billing: this needs the pay-as-you-go plan (Firebase "Blaze"). Personal use of this
   server stays inside Google's free monthly allowance, but add a budget alert anyway.
3. Search for "Cloud Run functions" > Create function.
   - Service name: payday-server        - Region: same as your database if offered
   - Trigger: HTTPS, Authentication: "Allow unauthenticated invocations"
     (safe: the code itself only answers your Google account)
   - Expand "Container, networking, security" > Variables & secrets > add these variables:
       PLAID_CLIENT_ID   = (from step A2)
       PLAID_SECRET      = (from step A2)
       PLAID_ENV         = production
       ALLOWED_ORIGIN    = https://yianni1997.github.io        (origin only, NO path)
       ALLOWED_EMAIL     = the Google email you sign in to Payday with
   - Next. Runtime: Node.js 20 (or newer). Entry point: payday
   - In the inline editor, replace the contents of index.js and package.json with the two
     files in the "server" folder of the Payday zip. Click Deploy and wait a few minutes.
4. Open the deployed function, copy its URL (looks like https://...run.app).

PART C - IN PAYDAY
1. Settings > sign in with Google.
2. Accounts tab > paste the URL under "Your server link".
3. Tap Connect a bank. Do Chase first (checking and the Amazon Visa come in together),
   then PayPal. Do this from Chrome, not the home-screen app icon.
4. Under each connected account, check the dropdown says the right source
   (Chase checking, Chase Amazon card, PayPal activity, PayPal Mastercard...).
5. Tap "Pull this paycheck". Charges for this paycheck appear in Review.
   Pending charges are skipped until they post. Re-pulling is safe: anything already
   imported or confirmed is skipped.

UPDATING YOUR SERVER FOR v42 (bank balances for Net worth and the low-checking warning)
1. console.cloud.google.com > Cloud Run functions > payday-server > Edit source (or "Source" tab > Edit).
2. Replace index.js with the new server/index.js from this zip. package.json is unchanged.
3. Save and redeploy. Wait a few minutes.
4. In Payday, open the Accounts tab once. Balances now show on Plan > Net worth.
Everything else in v42 works without this step.

PART D - AUTOMATIC PULLS AND PHONE ALERTS (v43, optional, about 10 minutes)
1. Update the server: Cloud Run functions > payday-server > Edit source. Replace BOTH index.js and
   package.json with the ones in this zip's "server" folder (package.json adds "web-push").
2. Add one more variable (Variables & secrets):
       CRON_SECRET = any long random text you make up, e.g. 7f3k29xq-payday-81mz
   Save and redeploy.
3. Search for "Cloud Scheduler" > Create job.
   - Name: payday-auto-pull     - Frequency: 0 */3 * * *   (every 3 hours)   - Time zone: yours
   - Target type: HTTP, Method: GET
   - URL: your server link + ?cron= + your CRON_SECRET, for example
       https://payday-server-xxxx.run.app/?cron=7f3k29xq-payday-81mz
   Create. Then tap "Force run" once. The first run only takes charges from the last 3 days.
4. On each phone or computer you want alerts on: open Payday > Accounts >
   "Turn on alerts on this device", allow notifications, then "Send a test".
   iPhone: alerts only work when Payday is opened from the home-screen icon.
How it works: every 3 hours the server asks Plaid for new posted charges and drops them where
only your signed-in Payday can read them. Next time Payday is open they go to Review like a pull.
Cloud Scheduler gives 3 free jobs a month, so this stays free.
Security log: failed or suspicious requests are logged. In Google Cloud > Logging, search
payday_security to see them.

GOOD TO KNOW
- The PayPal Mastercard is issued by Synchrony and often can't be connected. If it doesn't
  show up, keep using a CSV or PDF for it on the Import tab (PDF import is built in).
- If Chase says it isn't available or asks for approval, Plaid may need you to finish an
  OAuth/institution approval step in its dashboard. Look for it there.
- Your bank login goes to Plaid and the bank only. Plaid's access token is stored in a
  database collection the app itself cannot read (your Firestore rules only open users/<you>).
- To disconnect a bank: Accounts tab > Remove.

LIFEBUD LINK, SAFER VERSION (v49, about 5 minutes)
The old LifeBud code contained your Google login. The new one only lets LifeBud read the summary.
1. Update the server: replace index.js with the one in this zip's server folder. Redeploy.
2. Let the server make sign-in keys: console.cloud.google.com > IAM & Admin > IAM. Find the service
   account your function runs as (Cloud Run functions > payday-server > Details shows it; often
   "...-compute@developer.gserviceaccount.com"). Edit it (pencil) > Add another role >
   "Service Account Token Creator". Save. Wait a minute.
3. Firestore rules: Firebase console > Firestore > Rules. Paste the rules from README.txt
   (step 4, now with a LifeBud part) and Publish.
4. In Payday: Settings > Sync > LifeBud > Copy LifeBud code. Paste it in LifeBud within the hour.
5. Turn off the old code: Payday > Settings > Sync > sign out, then sign back in. That ends the
   Google login the old code carried. (Also delete the old code anywhere you pasted it.)
